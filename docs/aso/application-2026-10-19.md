# 스토어 ASO 콘솔 적용 기록

적용일: 2026-10-19. 사용자가 승인한 한국어 ASO 문구와 스크린샷만 반영했다. 새 Google Play 그래픽 이미지(1024×500)는 사용자 요청으로 제외하고 기존 이미지를 유지했다.

## Google Play

- 앱: `com.jihyuk.potatodiary`. 기본 한국어 `ko-KR` 등록정보만 수정했다.
- 변경 항목: 앱 이름, 간단한 설명, 전체 설명, 휴대전화 스크린샷의 네 항목이다. 콘솔의 게시 개요에서도 네 항목만 제출 대상으로 표시됐다.
- 기존 휴대전화 이미지 두 장을 새 여섯 장으로 교체했다. 순서는 `01-growth.png` → `02-emotion.png` → `03-photo.png` → `04-widget.png` → `05-search.png` → `06-drafts.png`다.
- 기존 그래픽 이미지의 URL이 수정 전후 동일함을 확인했다. 앱 아이콘과 다른 폼 팩터의 자산도 유지했다.
- 생성한 노을 사진을 포함하는 `03-photo.png`만 AI 생성 애셋으로 표시했다. 나머지 캐릭터와 앱 화면은 기존 자산·실제 촬영 화면이다.
- **검토 전송 완료.** 게시 개요가 ‘검토 중인 변경사항’으로 바뀌었고, 자동 검사를 성공적으로 마치면 검토를 위해 전송된다고 안내한다. 공개 승인·반영 완료 상태는 아니다.
- 관리형 게시가 사용 중지된 기존 설정을 유지했다. AAB·프로덕션 트랙·출시 설정은 변경하지 않았다.

## App Store Connect

- 앱: Apple ID `6739600096`, `com.example.tradeDiary`.
- 출시된 1.0.16은 메타데이터와 이미지가 잠겨 있어 다음 버전 **1.0.17 초안**을 생성했다. 상태는 ‘제출 준비 중’이다.
- 한국어 앱 이름·부제·설명·키워드를 등록 파일과 동일하게 저장했다.
- Dynamic Island 지원 iPhone 대형 디스플레이에 1320×2868 PNG 여섯 장을 번호순으로 업로드했다. 기존 세 장의 연결을 해제했으며 원본은 자산 보관함에 유지된다.
- 중형 디스플레이도 새 여섯 장을 ‘기존 자산 사용’으로 표시하는 것을 확인했다. iPad·Apple Watch·다른 언어는 수정하지 않았다.
- **초안 저장 완료.** 1.0.17 빌드가 아직 연결되지 않아 심사 제출·공개 출시는 진행하지 않았다. 저장소 버전·빌드 번호는 이번 메타데이터 적용에서 변경하지 않았다.
- 계정 첫 화면에는 업데이트된 Apple Developer Program 계약을 계정 소유자가 검토·동의해야 기존 앱 업데이트 및 신규 제출을 할 수 있다는 안내가 있었다. 계약에는 동의하지 않았다.
- 다음 릴리즈에서 저장소의 `develop` → `master` PR 절차와 버전·빌드 번호 검증을 거쳐 1.0.17 빌드를 준비하고, 계약 상태·릴리즈 노트·심사 정보를 확인한 뒤 제출해야 한다. 로컬 `submit` lane은 실행하지 않았다.

## 로컬 산출물

- [전체 갤러리](previews/index.html): 스크린샷 12장만 표시한다.
- `build/aso/store-previews-ko.zip`: iOS 6장과 Android 6장만 포함한다. `featureGraphic.png`와 검토용 모아보기는 제외했다.
- [등록 문구·제작 안내](README.md)와 [재생성 도구](../../tool/aso/README.md)를 함께 갱신했다. 그래픽 재생성은 명시적으로 `--feature-graphic`을 지정할 때만 실행한다.

콘솔에 저장·전송한 결과와 실제 공개 스토어 반영은 구분한다. Play 검토 결과와 iOS 심사·출시 후 공개 페이지는 별도로 확인해야 한다.
