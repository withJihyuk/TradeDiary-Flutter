# 제작용 예시 사진

`sunset.png`는 2026-10-19 내장 `imagegen` 도구로 생성한 풍경 이미지다. 미리보기의 사진 일기 화면에만 사용하며 사용자 사진이나 운영 데이터를 사용하지 않았다. 앱 번들에 추가하지 않는다.

생성 프롬프트:

> Use case: photorealistic-natural. Asset type: sample photo embedded inside a Korean diary app store screenshot, not a complete app screenshot. Create one warm, natural smartphone photograph of a peaceful riverside walking path at sunset in South Korea: soft peach and pale blue sky, golden light reflecting on the calm river, distant low hills and a few leafy trees along a simple path. A gentle everyday after-work moment, clean landscape composition, believable photography, restrained colors, no people, no buildings with legible signage, no text, no logos, no watermarks, no UI or frames. Landscape aspect ratio approximately 3:2, high quality.

투명 배경은 사용하지 않았다. 감자 그림·로고·글꼴은 저장소의 기존 자산이며 생성형 모델로 다시 그리지 않았다.
